## About

Add a conversational AI helper to the completed Hoot application. Build a
protected Django endpoint for Gemini, then connect it to a new React page with
multi-turn state, waiting feedback, error recovery, and a clear action.

## Learning objectives

- Protect third-party API keys on the backend.
- Validate and translate conversation messages.
- Call an external AI provider from DRF.
- Manage a multi-turn asynchronous flow in React.
- Explain privacy, quota, and reliability limits.
